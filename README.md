# gravity-simulation
A sandbox/challenge game with levels to complete using real gravity formulas to simulate launching a spaceship.

Up arrow for boost, mouse direction is the boost direction
Space to launch
D for debug mode

ARTEMIS mode: Flyby the moon and return to earth

ORBIT insertion mode: Stay in the highlighted region

SLINGSHOT mode: Escape earth with more velocity than your entering velocity, using the moon

Freeplay is self explanatory. (i hope)

Have fun, surprises are in the game :)
